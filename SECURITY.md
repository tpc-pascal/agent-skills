# Chính sách bảo mật

## Báo cáo lỗ hổng
Dùng GitHub private vulnerability reporting (tab Security → Report a vulnerability), không mở issue công khai.

## Phạm vi
Repo chứa agent skill (markdown) và shell script, không có dịch vụ chạy nền; không kèm secret nào, CI có quét rò rỉ. Các skill tải theo phiên chạy với quyền agent của người dùng — hãy xem lại nguồn bên thứ ba trước khi dùng.
